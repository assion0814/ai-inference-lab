## 三、验证 2：外挂到真实模型（❌ 失败，但发现并修复了两个 bug）

### 3.1 实验设计

```
任务（4 个，按"需要多少步"排序）:
  T1. 多步模加（10 项 mod 7）     — 需要累积
  T2. 模幂（a^b mod 7）           — 需要 log(b) 步
  T3. 四位数加法（mod 7）          — 需要进位传播
  T4. 嵌套括号（((a+b)*c-d) mod 7）— 语法树深度

外挂设计:
  Base = Qwen2.5-0.5B（完全冻结）
  提取最后一层 hidden state（896 维）
  三臂对比（参数量对齐！）:
    A. 线性探针: 6,279 参数
    B. MLP 探针: 1,613,703 参数
    C. DEQ 探针: 1,612,807 参数（与 MLP 差 896）
  多 seed（3 个）取均值
```

### 3.2 ★ 发现并修复两个数学 bug

**这是本轮最重要的技术发现。我的第一版 DEQ 实现有两个错误：**

#### Bug 1：J^T v 的计算顺序错误

```python
# 错误（第一版）:
def fT(v):
    return grad_z + (1 - z**2) * (v @ W.T)   # = (1-z²)⊙(Wv)

# 正确:
def fT(v):
    return grad_z + ((1 - z**2) * v) @ W.T   # = W((1-z²)⊙v)
```

**推导：**
```
J_{ij} = ∂f_i/∂z_j = (1-z_i²) W_{j,i}
(J^T v)_j = Σ_i J_{ij} v_i = Σ_i W_{j,i}[(1-z_i²)v_i] = (W @ ((1-z²)⊙v))_j
```

**错误影响：梯度相对误差 143.8%（U/W 参数），head 正常。**

#### Bug 2：W 和 U 的梯度都需要转置

```python
# 错误:
gW = dz.T @ z    # 算的是 dz_j · z_k
gU = dz.T @ x    # 形状错 (d_eq, d_in)

# 正确:
gW = z.T @ dz    # 算的是 z_j · dz_k
gU = x.T @ dz    # 形状对 (d_in, d_eq)
```

**推导：**
```
u_i = Σ_m z_m W_{m,i} + Σ_m x_m U_{m,i} + b_i
∂u_i/∂W_{jk} = δ_{ik} z_j  →  dL/dW_{jk} = z_j · dz_k
∂u_i/∂U_{jk} = δ_{ik} x_j  →  dL/dU_{jk} = x_j · dz_k
```

**修复后验证：**
```
参数    隐式范数      展开范数      相对误差
W        7.91e+01   7.91e+01   1.69e-07  ✅
b        1.27e+01   1.27e+01   1.56e-07  ✅
U        7.27e+01   7.27e+01   1.56e-07  ✅
```

**教训：隐式微分的正确性必须用解析解/展开解验证，不能假设。**
**这正是 equilibrium-lab 的 E1 强调的"装置自检"原则。**

### 3.3 修复前后的对比（关键！）

```
                 修复前（梯度有 bug）          修复后（梯度正确）
任务              mlp     deq    deq-mlp      mlp     deq    deq-mlp
──────────────────────────────────────────────────────────────────────
T1 多步模加      0.236   0.156   -7.9pp      0.236   0.237   +0.2pp
T2 模幂          1.000   0.912   -8.8pp      1.000   1.000   +0.0pp
T3 四位数加法    0.139   0.144   +0.4pp      0.139   0.149   +1.0pp
T4 嵌套括号      0.799   0.256  -54.3pp      0.799   0.782   -1.8pp
```

**这是本轮最有价值的发现：**
- **修复前 DEQ 看起来"全面失败"（-54.3pp），但那是我的 bug 造成的假象**
- **修复后 DEQ ≈ MLP（+0.2pp / -1.8pp，都在噪声内）**

**如果没做梯度正确性验证，我会得出"DEQ 完全不行"的错误结论。**
**这是"装置自检"价值的活教材。**

### 3.4 最终结论

```
T1 多步模加:    linear 14.2% → mlp 23.6% → deq 23.7%    (DEQ ≈ MLP)
T2 模幂:        linear 100%  → mlp 100%  → deq 100%     (天花板效应)
T3 四位数加法:  linear 14.4% → mlp 13.9% → deq 14.9%    (全部接近随机)
T4 嵌套括号:    linear 31.1% → mlp 79.9% → deq 78.2%    (DEQ ≈ MLP)
```

**关键判读：**

1. **DEQ 与同参数量 MLP 持平**（+0.2pp / -1.8pp / +1.0pp / +0.0pp）
   → **"均衡迭代"本身没有带来额外增益**
   → 增益来自参数量，不是迭代机制

2. **T4 揭示真相**：非线性（MLP/DEQ）比线性探针高 48pp
   → 任务确实需要非线性
   → 但 DEQ 不比 MLP 更好

3. **T2 天花板**：hidden state 直接线性编码了模幂结果（只有 25 种组合）
   → 任务太简单，无法区分方法

4. **T3 全随机**：Qwen2.5-0.5B 的 hidden state 里没有四位数进位信息
   → 需要更大的模型或不同的提取位置

## 四、为什么外挂失败？（机制分析）

### 4.1 三个可能的原因

**原因 1：DEQ 作用在错误的层级**
```
外挂设计:  base → h(896) → DEQ → 分类
问题:      DEQ 只看到最后一层 hidden state
          "均衡迭代"应该在层间（隐式深度），不是在输出端
类比:      在 Transformer 最后一层后面加个 DEQ，等于给分类头加了个非线性特征变换
          这不是"均衡计算"，是"特征精炼"
```

**原因 2：没有与 base 联合训练**
```
当前:  base 冻结，只训 DEQ 探针
问题:  DEQ 需要学会"如何迭代"来配合 base 的表示
      但 base 的表示不是为 DEQ 准备的
类比:  给一个已经训练好的分类器加个随机初始化的迭代层
      迭代层需要自己学出一个不动点问题，太难
```

**原因 3：参数量对齐后，DEQ 的优势不显现**
```
DEQ:  d_eq × d_eq (W) + d_in × d_eq (U) = 896×896 + 896×896 = 1.6M
MLP:  896×896 × 2 = 1.6M（两个隐藏层）
问题:  同参数量下，MLP 的表达能力足够强
      DEQ 的"深度"优势需要更大的参数量差才能体现
```

### 4.2 修正后的判断

**用户设想的"外挂验证 → 改预训练模型"路径：**

```
第一步（外挂验证）: ❌ 不通过（DEQ ≈ MLP，无额外增益）
第二步（改预训练）:  ❌ 无依据（第一步都没通过，没理由投入）
```

**但这不意味着 DEQ 没有价值 —— 它意味着"简单外挂"这条路不通。**

**如果真的要用 DEQ，需要：**
1. **把 DEQ 插在层间**（如每 4 层插一个 DEQ）
2. **与 base 联合训练**（至少微调最后几层）
3. **用更大的任务**（真实语言建模，不是分类探针）
4. **用 torchdeq 的 deq-lm 完整实现**（98M 参数，Wikitext-103 上 PPL 21.85）

**这些都需要训练资源，V100 单卡可以做但周期长（估计 1-2 周）。**

  → 发现自己的 bug
  → 修复后结论变成"DEQ ≈ MLP"

**这正是 equilibrium-lab 的 PRE-REGISTRATION 强调的"装置自检"原则 —— 自检不过则实验作废。**
